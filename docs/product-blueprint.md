# 产品蓝图

## 当前产品规划

个人 AI 助手是模块化、优先本地使用的 AI 工作空间，提供项目接入、项目管理、个人知识库以及统一工作空间与 AI 对话。

| 模块 | 规划职责 | 当前状态 |
| --- | --- | --- |
| 1：项目接入与上下文管理 | 本地或 GitHub 独立接入及关联，获取结构、文件、版本和变更事实 | 优先规划，未实现 |
| 3：智能项目管理 | 进度可视化、任务、主动感知、执行证据、智能预核验与人工确认 | 优先规划，未实现 |
| 4：个人知识库 | 收藏、基础分类、搜索、AI 总结、基于资料问答 | 优先规划，未实现 |

编号沿用 Human 提供的规划，不推定存在已定义的模块 2。模块规划不是已承诺功能或实施授权。

## 当前正式开发范围

仅完成项目 Bootstrap：开发规范、基础文档、Git 初始化、公开前内容检查、Human 确认后的 GitHub 公开仓库创建与首次推送。当前没有授权模块业务开发。

正式边界见 [Project Brief](project-brief.md)，架构方向见 [Architecture](architecture.md)。

## 后续扩展方向

- Codex、DeepSeek Harness 等 Coding Agent 深度协作。
- 多项目高级管理。
- 根据实际需求增加其他能力。

以上为长期候选方向，没有确定排期、接口或实施承诺。

## 尚未决定的交互和技术细节

界面形态、导航、对话与任务交互、主动提醒方式、人工确认流程、模块间协作细节均待确定。技术栈、数据库、模型、接口、同步、安全及部署方案也未决定。

下一阶段应由 Human 明确首个场景、范围和验收条件；不得从本蓝图自动生成并实施全部功能。
