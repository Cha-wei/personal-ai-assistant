# Project Brief

## 项目身份与目的

- 项目名称：Personal AI Assistant（个人 AI 助手）。
- 目标用户：个人使用者；更具体的用户画像与使用场景尚未确定。
- 项目目标：建立模块化、优先本地使用的 AI 工作空间，整合项目上下文、智能项目管理、个人知识库与 AI 对话。
- 当前可验证成功标准：独立 Git 仓库采用 main；规范与基础文档完整；内容经 Human 确认后发布为独立 GitHub Public 仓库，并核验首次推送、远程文件和提交。

## 当前授权范围

- 当前正式开发范围仅为 Bootstrap：引入规范、初始化文档与 Git、检查公开内容，经 Human 确认后创建公开仓库并首次推送。
- 模块 1、3、4 为优先产品规划，尚未授权业务实现。详见[产品蓝图](product-blueprint.md)。
- 非目标：业务功能、Coding Agent 深度协作、多项目高级管理；本次不决定核心技术栈、框架、数据库或接口，不搭建复杂 CI、测试框架或基础设施。
- 约束：本地优先；模块职责清晰、低耦合高内聚；本地项目与 GitHub 可独立使用。不得公开凭证、个人隐私或本地配置；不得改动 Starter、覆盖未知文件、改写共享历史或擅自选择许可证。
- 正式范围批准依据：Human 于 2026-10-26 提供的“个人 AI 助手项目初始化与 GitHub 公开仓库创建”任务。公开仓库创建和推送需另获该任务要求的 Human 内容确认。

产品范围不自动扩大单次任务授权；新功能须明确目标、范围及验收条件。

## 待确认事项

- 各模块首个使用场景、MVP 边界与功能验收标准。
- 交互形态、运行平台、技术栈、存储、模型服务及凭证管理方案。
- 本地与 GitHub 关联、同步策略、权限与失败恢复行为。
- 资料格式、索引、AI 总结与问答的质量和隐私要求。
- 许可证、分支保护、后续验证与 CI 配置。
